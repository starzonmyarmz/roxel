# Palettes

A palette is the set of colors you paint with. Roxel ships with classic pixel-art palettes and lets you build your own.

## Built-in palettes

- Sweetie 16
- PICO-8
- DawnBringer 16 / 32
- Endesga 32
- NA16
- Basic

## User palettes

You can manage your own palettes from the inspector:

- **Add** a color to the current palette
- Create a **new** palette
- **Duplicate** an existing one as a starting point
- **Rename** and **delete**
- **Drag to reorder** swatches

User palettes persist between sessions.

## Importing & exporting palettes

Roxel reads and writes the **Adobe Swatch Exchange** (`.ase`) format, so you can move palettes between Roxel and other design tools. See [Import & Export](import-export.md).
