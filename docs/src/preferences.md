# Preferences & Themes

Roxel's UI is canvas-first: a single left inspector, a floating tool island, and — on Windows / Linux — a top-center menu pill. Everything is hideable so the model takes the whole screen.

## Themes

Choose **Light**, **Dark**, or **System** (follows your OS setting).

## Canvas appearance

Independent of the UI theme, you can set:

- **Canvas color** — the viewport background
- **Floor color** — the ground plane at `y = 0`
- **Floor grid lines** — optional Minecraft-style grid on the floor

A permanent RGB **axis triad** marks the world origin.

## Focus mode

Press `` ` `` (backtick) to toggle focus mode, which hides the inspector and all floating chrome for a distraction-free canvas. Press again to bring the UI back.
